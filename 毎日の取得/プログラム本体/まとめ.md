# ATS-Processors 統合フォルダ 作成完了

## 📦 作成内容

ats、herp、rikunabiの処理を1つのフォルダ「**ats-processors**」にまとめました。

### 📁 フォルダ構成

```
ats-processors/
├── ats.py                  # ATSメインスクリプト（HRMOS/Talentio/JobCan）
├── rikunabi.py            # リクナビスクレイパー
├── config.yaml            # ATS認証設定ファイル
├── requirements.txt       # 依存パッケージ一覧
├── README.md              # 詳細ドキュメント
│
├── utils/                 # 共通ユーティリティ
│   ├── __init__.py
│   ├── login_direct.py    # ログイン処理
│   ├── scraping.py        # スクレイピング処理
│   └── data_format.py     # データフォーマット
│
├── herp/                  # Herpスクレイパー
│   ├── herp.py           # メインスクリプト
│   ├── herp.txt
│   ├── herp_urls_new.txt
│   └── output_herp_jobs/ # 出力CSVファイル（160件）
│
└── output/               # 各ATS出力ディレクトリ
    ├── hrmos/
    ├── talentio/
    ├── jobcan/
    └── rikunabi/
```

## 🚀 クイックスタート

### 1. セットアップ

```bash
cd /Users/ryuga.uchiyama/git/ats-crawling/ats-processors

# 依存パッケージインストール
pip install -r requirements.txt

# Playwrightブラウザインストール
playwright install chromium
```

### 2. 実行方法

#### ATS データ収集

```bash
# ats.pyを編集してメディア選択
vim ats.py
# use_media = "hrmos"  # または "talentio", "jobcan"

# 実行
python ats.py
```

#### リクナビ データ収集

```bash
python rikunabi.py
```

#### Herp データ収集

```bash
cd herp
python herp.py
```

## 📝 出力ファイル形式

### ATS出力

```
output/{media}/{media}_{category}_item_list_{date}.csv
```

例:

- `output/hrmos/hrmos_WEB_item_list_2026-03-18.csv`
- `output/talentio/talentio_CRS_item_list_2026-03-18.csv`

### リクナビ出力

```
output/rikunabi/rikunabi_{category}_item_list_{date}.csv
```

### Herp出力

```
herp/output_herp_jobs/herp-{category}-{date}.csv
```

## 🔧 主要機能

### 共通ユーティリティ（utils/）

1. **login_direct.py** - ログイン処理
   - `login_hrmos()` - HRMOSログイン
   - `login_talentio()` - Talentioログイン
   - `login_jobcan()` - JobCanログイン

2. **scraping.py** - スクレイピング処理
   - `crawl_site()` - HRMOS求人取得
   - `crawl_talentio()` - Talentio求人取得
   - `crawl_jobcan()` - JobCan求人取得

3. **data_format.py** - データフォーマット統一
