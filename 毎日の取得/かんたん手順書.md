# 求人データ取得 かんたん手順書

専門的な知識は不要で、操作は基本的にダブルクリックのみです。

> **Windowsをお使いの方へ**: 「.command」はMac用です。先に一番上のフォルダの **「Windowsで使うとき.md」** をご確認のうえ、**「.command」の付かない同じ名前のファイル(Windowsバッチファイル)** をダブルクリックしてください。セキュリティの確認画面が出て実行できない場合の対処も、そちらに記載しています。

---

## 最初の1回だけ(このフォルダをもらったら)

1. 「ats-processors」フォルダの中の **「毎日の取得」** フォルダを開く
2. フォルダの中の **「はじめにこれ.command」をダブルクリック**
   - 「開発元を確認できません」と表示された場合: そのファイルを **右クリック → 「開く」→「開く」**
   - 「"インストール"しますか?」と表示された場合は「インストール」を押し、完了後にもう一度ダブルクリック
3. 画面に「準備完了」と表示されたら完了です(5〜10分程度かかります)

この準備は最初の1回のみで、翌日以降は不要です。

---

## 毎日やること(平日)

1. **「実行する.command」をダブルクリック**
   - 曜日は自動で判定されるため、曜日ごとの違いを意識する必要はありません
   - 土日に実行した場合は、その旨が表示されるのみで何も実行されません
2. 終わるまで待つ
   - **実行中に自動でブラウザが開きますが、操作したり閉じたりしないでください**(HERPだけは画面を出さずに裏で動きます)
   - 月曜は1時間以上(HERPだけで約2時間)、他の曜日は数十分程度かかります
   - 実行中の画面(ターミナル)も閉じずにお待ちください
3. 完了すると、画面に **その日に作成されたファイルの一覧が表示されます**
4. そのファイルを Google Drive に入れる(下の「Driveへの入れかた」)

---

## Driveへの入れかた(最後にやる)

できたファイルは、次の Google Drive フォルダに入れます:

https://drive.google.com/drive/u/0/folders/1g2J2TNnGJLqwR1jMyIHwn1OB4l1HroUU

1. 上のリンクをブラウザで開く(ブックマークしておくと便利です)
2. Drive の中に **カテゴリごとのフォルダ**(WEB / IN / CRS / CRG / コンサル)があります
3. 今日できたファイルを、**名前に入っているカテゴリと同じフォルダ**にドラッグ&ドロップする
   - 例: `hrmos_WEB_item_list_2026-06-04.csv` → **WEB** フォルダへ
   - 例: `rikunabi_コンサル_item_list_20260604.csv` → **コンサル** フォルダへ
   - ファイル名に **IN_DS** と入っているものは → **IN** フォルダへ(Drive側は「IN」という名前です)
4. 実行した媒体のファイルが全部入れ終わったら、その日の作業は完了です

※ ファイルの場所が分からなくなった場合: このフォルダの中の **「output」** に媒体ごとにまとまっています(HERPは「output」の中の「herp」にあります)

## うまくいかないとき

1. **もう一度「実行する.command」をダブルクリック**(多くの場合これで解消します)
2. それでも解消しない場合は、**内山までご連絡ください**
   - 実行画面のスクリーンショットを添えていただくとスムーズです

### よくあること

- **実行中にブラウザが開く** → 正常な動作です。操作せずにお待ちください
- **なかなか終わらない** → 月曜(リクナビ・HERP)は特に時間がかかります。閉じずにお待ちください
- **ファイルの中身が空・1行しかない** → 再度実行してください。解消しない場合は内山まで
- **HERPで「🔴 検算NG — このデータは納品しないでください」と出た** → そのカテゴリのファイルはDriveに入れず、「媒体を選んで実行.command」の **7) HERP(カテゴリを指定)** でそのカテゴリだけやり直してください。もう一度NGなら画面のスクリーンショットを内山まで
- **HERPが途中で止まった(パソコンを閉じた・ネットが切れた等)** → 終わったカテゴリのファイル(`herp-CRG-日付.csv` など)は残っています。「媒体を選んで実行.command」の **7)** で残りのカテゴリ(CRG / CRS / IN / WEB / コンサル のうち出来ていないもの)だけ実行すれば、最初からやり直す必要はありません
- **「準備がまだのようです」と表示される** → 「はじめにこれ.command」を先に実行してください
