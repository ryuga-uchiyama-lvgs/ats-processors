# 月次集計 かんたん手順書

毎月1回、障害者雇用の求人サイト5つからデータを集めて、納品用のフォルダを作る作業です。
専門的な知識は不要で、操作は基本的にダブルクリックのみです。

> **Windowsをお使いの方へ**: 「.command」はMac用です。先に一番上のフォルダの **「Windowsで使うとき.md」** をご確認のうえ、**「.command」の付かない同じ名前のファイル(Windowsバッチファイル)** をダブルクリックしてください。セキュリティの確認画面が出て実行できない場合の対処も、そちらに記載しています。

---

## 最初の1回だけ(このフォルダをもらったら)

1. 「ats-processors」フォルダの中の **「月次集計」** フォルダを開く
2. フォルダの中の **「はじめにこれ.command」をダブルクリック**
   - 「開発元を確認できません」と表示された場合: そのファイルを **右クリック → 「開く」→「開く」**
   - 「"インストール"しますか?」と表示された場合は「インストール」を押し、完了後にもう一度ダブルクリック
3. 画面に「準備完了」と表示されたら完了です(5〜10分程度かかります)

この準備は最初の1回のみで、来月以降は不要です。

---

## 毎月やること(3ステップ)

### その① データを取る

1. **「①取得する.command」をダブルクリック**
2. 終わるまで待つ(30分〜2時間程度)
   - **実行中に自動でブラウザが開きますが、操作したり閉じたりしないでください**
   - 実行中の画面(ターミナル)も閉じずにお待ちください
3. 「4媒体のデータ取得が終わりました」と表示されたら完了です

### その② dodaチャレンジだけ手作業で取る

dodaチャレンジのみ自動取得ができないため、ページを手作業でコピーします。

1. ブラウザ(Chrome)で dodaチャレンジの求人検索結果ページを開く
   - https://doda.jp/challenge/ から求人検索
2. ページの下のほうにある **「もっと見る」ボタンを、表示されなくなるまで押し続ける**
   - これで全ての求人が1ページに表示されます(回数が多い場合がありますが、最後まで押してください)
3. 求人一覧のあたりで **右クリック → 「検証」** を押す(画面の横に開発者ツールが開きます)
4. 開発者ツールの中で、**求人一覧全体を囲んでいる行** を選んで **右クリック → Copy → Copy outerHTML**
   - 開発者ツールの行にマウスを乗せると、ページ側の対応する場所がハイライトされます。**求人一覧全体がハイライトされる行**を選んでください
5. このフォルダの **「dodaここに貼る.txt」** を開いて、**中身を全て消してから貼り付けて保存**

### その③ 集計する

1. **「②集計する.command」をダブルクリック**(数分で完了します)
2. 「7ファイルそろっています」と表示されたら完了です
3. このフォルダにできた **「日付_集計」フォルダ(例: 20260630_集計)を丸ごと** Google Drive の所定フォルダにアップロードする
4. アップロードしたら依頼元に完了報告して、今月の作業は完了です

## うまくいかないとき

1. **もう一度同じ.commandファイルをダブルクリック**(多くの場合これで解消します)
2. それでも解消しない場合は、**内山までご連絡ください**
   - 実行画面のスクリーンショットを添えていただくとスムーズです

### よくあること

- **実行中にブラウザが開く** → 正常な動作です。操作せずにお待ちください
- **「準備がまだのようです」と表示される** → 「はじめにこれ.command」を先に実行してください
- **②で「HTMLが貼られていないようです」と表示される** → その②の貼り付けを行ってから、もう一度②を実行してください
- **②で「ファイルが7個ありません」と表示される** → 画面の案内に沿って、足りない媒体を①からやり直してください
- **件数が先月から大きく違う(3割以上)** → サイト側の仕様が変わった可能性があります。内山までご連絡ください

## 注意

- **「プログラム本体」フォルダ内のファイルは変更しないでください**(操作が必要なのは、この手順書に出てくるファイルのみです)
- 同じ媒体の取得は1日1回までにしてください(取得先サイトへの負荷を避けるため)
