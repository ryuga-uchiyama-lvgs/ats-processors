# 障害者雇用媒体 月次集計 手順書

毎月1回、障害者雇用枠の求人媒体5つから求人情報を取得し、企業名の重複を削除した集計CSVを作成して納品する作業の手順書です。

## 対象媒体(5媒体)

| 媒体 | 取得方法 | フォルダ |
|---|---|---|
| atGP | スクリプト自動 | `atGP/` |
| LITALICO仕事ナビ | スクリプト自動 | `LITALICO/` |
| BABナビ | スクリプト自動 | `BABNAVI/` |
| マイナビパートナーズ紹介 | スクリプト自動 | `マイナビパートナーズ/` |
| dodaチャレンジ | **手動**(HTML保存→変換スクリプト) | `doda-challenge/` |

## 全体フロー

```
① 4媒体スクレイピング実行(各5〜30分)
② dodaチャレンジを手動取得 → parse_jobs.py でCSV化
③ monthly_dedup.py 実行 → YYYYMMDD_集計 フォルダ生成
④ 検品(ファイル数・件数チェック)
⑤ Google Drive へ納品
```

## 初回セットアップ(最初の1回だけ)

### 必要なファイル一式

作業フォルダ(例: `~/月次集計_引き継ぎ/`)に以下を配置してください。**フォルダ構成・フォルダ名は変えないこと**(集計スクリプトがこの構成を前提にしています)。

```
月次集計_引き継ぎ/
├── atGP/                  scrape_atgp.py, prefecture-id.csv, requirements.txt
├── LITALICO/              scrape_snabi_jobs.py, requirements.txt
├── BABNAVI/               scraper.py, requirements.txt
├── マイナビパートナーズ/   scraper.py, requirements.txt
├── doda-challenge/        parse_jobs.py
├── monthly_dedup.py
└── 月次集計_手順書.md(本ファイル)
```

### 環境構築

Python 3.9 以上が必要です(`python3 --version` で確認)。

```bash
cd ~/月次集計_引き継ぎ
pip3 install playwright
playwright install chromium
```

## 毎月の作業手順

### Step 1: 4媒体のスクレイピング実行

各フォルダに移動してスクリプトを実行します。1つずつ順番でも、ターミナルを4つ開いて並行実行でもOKです。

```bash
# atGP(対象: 埼玉/千葉/東京/神奈川/愛知/大阪/福岡)
cd ~/月次集計_引き継ぎ/atGP
python3 scrape_atgp.py

# LITALICO仕事ナビ
cd ~/月次集計_引き継ぎ/LITALICO
python3 scrape_snabi_jobs.py

# BABナビ
cd ~/月次集計_引き継ぎ/BABNAVI
python3 scraper.py

# マイナビパートナーズ
cd ~/月次集計_引き継ぎ/マイナビパートナーズ
python3 scraper.py
```

実行が終わると、各フォルダに当日日付のCSVが生成されます:

- `atgp_jobs_YYYYMMDD_HHMMSS.csv`
- `snabi_jobs_YYYYMMDD_HHMMSS.csv`
- `babnavi_jobs_YYYYMMDD_HHMMSS.csv`
- `mynavi_partners_jobs_YYYYMMDD_HHMMSS.csv`

> 所要時間の目安: 各5〜30分。進捗はターミナルに表示されます。
> エラーで止まった場合は「トラブルシューティング」参照。

### Step 2: dodaチャレンジの手動取得

dodaチャレンジだけは自動スクリプトがないため、手動でHTMLを取得します。

1. ブラウザで dodaチャレンジの求人検索結果ページ(`https://doda.jp/challenge/` の求人検索)を開く
2. 検索結果ページのHTMLを取得する(開発者ツール → Elements → `<html>` を右クリック → Copy outerHTML)
3. `doda-challenge/doda-challenge.txt` に貼り付けて**上書き保存**(複数ページある場合は全ページ分のHTMLを同じファイルに連結して貼り付け)
4. 変換スクリプトを実行:

```bash
cd ~/月次集計_引き継ぎ/doda-challenge
python3 parse_jobs.py
```

→ `doda-jobs.csv` が更新されます(求人件数がターミナルに表示されるのでメモしておく。目安: 1,800件前後)。

### Step 3: 正規化・重複削除の実行

5媒体のCSVが揃ったら、集計スクリプトを実行します。

```bash
cd ~/月次集計_引き継ぎ
python3 monthly_dedup.py
```

- 日付は自動で当日(YYYYMMDD)になります。日付を指定したい場合: `python3 monthly_dedup.py 20260701`
- 各媒体フォルダの**最新日付のCSV**を自動で読み込みます
- `[警告] ...日付が一致しません` と出た場合は、その媒体のスクレイピングを実行し忘れています(Step 1からやり直し)
- `[SKIP]` が出た場合も同様に未実行の媒体があります

処理内容(自動):
1. 全角英数字・記号→半角への正規化(★☆除去、【】→[] など)
2. 媒体間で同じ企業が重複している場合、**先に出現した媒体を優先**して後の媒体から削除(優先順: atGP → LITALICO → dodaチャレンジ → BABナビ → マイナビパートナーズ)
3. `YYYYMMDD_集計/` フォルダに結果を出力

### Step 4: 検品

`YYYYMMDD_集計/` フォルダに **7ファイル** あることを確認:

- [ ] `atGP_YYYYMMDD.csv`
- [ ] `LITALICO仕事ナビ_YYYYMMDD.csv`
- [ ] `dodaチャレンジ_YYYYMMDD.csv`
- [ ] `BABナビ_YYYYMMDD.csv`
- [ ] `マイナビパートナーズ_YYYYMMDD.csv`
- [ ] `all_companies_deduped_YYYYMMDD.csv`(全媒体統合の企業名一覧)
- [ ] `removed_duplicate_companies_YYYYMMDD.csv`(重複削除した企業の一覧)

実行後のサマリの件数が、前月から大きく乖離していないか確認します(±30%を超えていたら要確認)。

参考: 2026/06/01 実行時の件数

| 媒体 | 取得件数 | 重複削除後 |
|---|---|---|
| atGP | 1,782 | 1,782 |
| LITALICO仕事ナビ | 2,584 | 2,051 |
| dodaチャレンジ | 1,813 | 1,058 |
| BABナビ | 1,221 | 1,068 |
| マイナビパートナーズ | 466 | 202 |
| 全媒体ユニーク企業数 | — | 2,231 |

最後に、媒体別CSVをどれか1つExcelで開いて文字化けしていないことを確認(UTF-8 BOM付きなのでそのまま開けます)。

### Step 5: 納品

`YYYYMMDD_集計` フォルダを**フォルダごと** Google Drive の所定フォルダにアップロードします。

- 納品先: 【DriveフォルダのURLをここに記入】
- アップロード後、依頼元に完了報告(各媒体の件数サマリを添えると親切です)

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| `Executable doesn't exist` | `playwright install chromium` を実行 |
| `playwright not found` | `pip3 install playwright` を実行 |
| タイムアウトエラー | ネットワークを確認して再実行。改善しない場合はスクリプト内の `timeout` 値を増やす |
| 取得件数が 0 件 / 前月から激減 | サイトのHTML構造が変わった可能性。作業を止めて依頼元に報告 |
| `monthly_dedup.py` で `[警告] 日付が一致しません` | その媒体の Step 1 を実行し忘れている |
| dodaチャレンジの件数が極端に少ない | HTMLの貼り付けが一部ページのみになっている。全ページ分を連結したか確認 |

## 注意事項

- 各スクリプトはサーバー負荷軽減のためページ間に1〜5秒の待機を入れています。**待機時間を短くしないでください**
- 同じ媒体への実行は1日1回までにしてください
- 取得データの取り扱いは社内ルールに従ってください
