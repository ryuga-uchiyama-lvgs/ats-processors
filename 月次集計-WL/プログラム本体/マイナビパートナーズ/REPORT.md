## 技術仕様

### スクレイピング手法
- Playwright（ヘッドレスChromium）を使用
- User-Agent: Windows Chrome 120相当に設定
- 各ページ取得後に1〜5秒のランダムwaitを実装
- リトライ処理実装済み（最大3回）

### 出力形式
- UTF-8（BOM付き）のCSV形式
- ファイル名: `mynavi_partners_jobs_YYYYMMDD_HHMMSS.csv`
- Excelで文字化けせずに開ける形式

### コード設計
- 設定値（URL、セレクタ等）はスクリプト先頭で変数定義
- 進捗状況をprint文で詳細に出力
- エラー処理とリトライ機能を実装

### サンプルデータ
`sample_output.csv` に実際に取得した1ページ目のデータ（20件）を保存済み。
以下の企業の求人が含まれます：
- 株式会社シーイーシー
- アクセンチュア株式会社
- ALH株式会社
- 令和アカウンティング・ホールディングス株式会社
- その他（社名非公開含む）

## 実行方法

### 1. 環境構築
```bash
# Playwrightをインストール
pip install -r requirements.txt

# Chromiumブラウザをインストール
playwright install chromium
```

### 2. スクレイピング実行
```bash
python scraper.py
```

### 3. 実行結果
実行すると以下のファイルが生成されます：
- `mynavi_partners_jobs_YYYYMMDD_HHMMSS.csv` - 取得した全求人データ
