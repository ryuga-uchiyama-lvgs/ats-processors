# BABナビ 求人情報スクレイパー

このスクリプトは、BABナビ（障害者雇用枠の求人サイト）から求人情報を自動的に取得します。

## 取得できる情報

各求人について、以下の情報を取得します：

- **タイトル**: 求人のタイトル
- **求人URL**: 詳細ページへのリンク
- **会社名**: 募集企業名
- **画像URL**: 企業ロゴや求人画像
- **タグ/アイコン**: 「年間休日120日以上」「福利厚生に自信あり」などの特徴
- **勤務地**: 勤務場所
- **募集職種**: 募集している職種
- **雇用・募集形態**: 正社員、契約社員など
- **給与・昇給・賞与・手当など**: 給与情報
- **勤務方法**: 通勤型、在宅・テレワークなど
- **基本給**: 基本給（記載がある場合）

## セットアップ

### 1. 必要なパッケージのインストール

```bash
pip install -r requirements.txt
```

### 2. Playwrightブラウザのインストール

```bash
playwright install chromium
```

## 使い方

### 基本的な使用方法

```bash
python scraper.py
```

このコマンドを実行すると、以下の処理が行われます：

1. 指定されたURLから全ページをスクレイピング
2. CSVファイルとJSONファイルに結果を保存
3. ファイル名は自動的にタイムスタンプ付きで生成されます（例：`babnavi_jobs_20250111_123456.csv`）

### カスタマイズ

スクリプト内の `base_url` を変更することで、異なる検索条件の求人を取得できます：

```python
# scraper.py の main() 関数内
base_url = 'https://bab-navi.dandi.co.jp/zenkoku/PC13,14,12,11,23,27,40'
```

## 出力ファイル

### CSV形式
- ファイル名: `babnavi_jobs_YYYYMMDD_HHMMSS.csv`
- エンコーディング: UTF-8 with BOM（Excelで開く際に文字化けしない）
- タグは カンマ区切りの文字列として保存

### JSON形式
- ファイル名: `babnavi_jobs_YYYYMMDD_HHMMSS.json`
- エンコーディング: UTF-8
- タグは配列として保存

## 注意事項

- スクリプトは各ページ間で1秒の待機時間を設けています（サーバー負荷軽減のため）
- 大量のページをスクレイピングする場合は、実行に時間がかかる可能性があります
- ウェブサイトの利用規約を遵守してください

## トラブルシューティング

### エラー: `playwright._impl._api_types.Error: Executable doesn't exist`

Playwrightのブラウザがインストールされていません。以下を実行してください：

```bash
playwright install chromium
```

### エラー: タイムアウトエラー

ネットワーク接続が遅い場合、タイムアウトを延長できます。
スクリプト内の `timeout=60000` の値を増やしてください。
