求人データ取得ツール 操作マニュアル

本ツールの初期設定から、日次・月次の運用、トラブル対応までを記載しています。基本的な操作はファイルのダブルクリックのみで完結します。初めてご利用になる場合は、上から順にご確認ください。

i概要

本ツールは、複数の求人サイトから求人データを取得し、Google Drive へ格納するためのものです。作業は「日次の取得」と「月次の集計」の2種類で、いずれもファイルをダブルクリックして処理の完了を待つ流れが中心です。

ご利用にあたって

作業は 「日次の取得（平日）」 と 「月次の集計（月1回）」 の2種類です。いずれも 初回のみ「初期設定」 が必要で、2回目以降は不要です。処理が途中で停止した場合は、同じファイルをもう一度実行すると解消することが多くあります。

重要

「プログラム本体」フォルダ内のファイルは、編集・移動・削除をしないでください。操作の対象は、本マニュアルに記載されているファイルに限られます。

1作業の全体像

最上位の「ats-processors」フォルダに、作業用フォルダが2つあります。実施する作業に応じて、該当するフォルダを開いて進めてください。

フォルダ実施時期内容
毎日の取得 平日に毎日 HRMOS・Talentio・JobCan・リクナビ・HERP の求人データを取得します。取得対象の媒体は曜日に応じて自動的に切り替わります。
月次集計-WL 月末に1回 障害者雇用の求人媒体5つ（atGP・LITALICO仕事ナビ・dodaチャレンジ・BABナビ・マイナビパートナーズ）を取得し、企業の重複を整理した納品用データを作成します。

2初期設定（初回のみ）

フォルダを受領後、作業を始める前に一度だけ初期設定を行います。「毎日の取得」「月次集計-WL」それぞれのフォルダで1回ずつ必要です。ご利用環境のタブを選択してください。

  1. 作業対象のフォルダを開きます。
    「ats-processors」内の「毎日の取得」または「月次集計-WL」。
  2. 「はじめにこれ.command」をダブルクリックします。
    ターミナル（黒い画面）が開き、設定が自動的に進みます。
  3. 確認画面が表示された場合は対応します。
    「開発元を確認できません」と表示された場合は、ファイルを右クリックして「開く」→「開く」を選択します。「インストールしますか」と表示された場合は「インストール」を選択し、完了後に再度ダブルクリックしてください。
  4. 「準備完了」と表示されれば設定は終了です。
    所要時間は5〜10分程度です。完了するまで画面を閉じないでください。
補足

「毎日の取得」ではデータ取得に Google Chrome を使用します。未導入の場合は google.com/chrome から導入してください。

注意：Windows では実行ファイルが異なります

末尾が「.command」のファイルは macOS 用です。Windows では、同名で「.command」が付かないファイル（種類が「Windowsバッチファイル」のもの）を実行してください。

  1. ZIP で受領した場合は、展開前にブロックを解除します。
    ZIP を右クリックして「プロパティ」を開き、下部に「許可する」のチェック欄があれば有効にして「OK」を押します。その後、右クリックから「すべて展開」を選択します（チェック欄が無い場合はそのまま展開して差し支えありません）。
  2. 作業フォルダ内の「はじめにこれ」（Windowsバッチファイル）を実行します。
    実行に必要な Python も自動的に導入されます。
  3. 「準備完了」と表示されれば設定は終了です。
セキュリティの確認画面が表示され、実行できない場合

「WindowsによってPCが保護されました」（青い画面）：「詳細情報」を押し、表示される「実行」ボタンを押します。

「セキュリティの警告」ダイアログ：「実行」を押します。毎回表示される場合は、ファイルを右クリックして「プロパティ」→「許可する」を有効化してください。

ダブルクリックしても反応がない／一瞬で閉じる：フォルダ上部のアドレスバーに cmd と入力して Enter を押し、開いた画面に対象ファイルをドラッグ＆ドロップして Enter を押します。

いずれでも解決しない場合：表示画面のスクリーンショットを添えてお問い合わせください。社内 IT 担当による解除が必要な場合があります。

Python の自動導入に失敗した場合（該当時のみ）

通常は不要です。「自動インストールができませんでした」と表示された場合のみ、以下を実施してください。

  1. python.org/downloads を開きます。
  2. 「Download Python 3.◯◯」からインストーラーを取得します。
  3. 最初の画面で「Add python.exe to PATH」を必ず有効にします。
  4. 「Install Now」を押し、完了後に「Close」で閉じます。
ポイント

初期設定は初回のみです。翌日以降・翌月以降に再度行う必要はありません。

3日次の取得作業（平日）

平日に1回、データを取得して Google Drive へ格納します。取得対象の媒体は曜日に応じて自動的に切り替わるため、曜日を意識して操作を変える必要はありません。

曜日ごとの取得対象（自動判定）

曜日取得対象の媒体所要時間の目安
月曜HRMOS ／ リクナビ ／ HERP1時間以上
火曜・木曜HRMOS ／ Talentio数十分
水曜・金曜HRMOS ／ JobCan数十分
土曜・日曜対象なし（実行しても処理は行われません）—

実行手順

  1. 「実行する.command」をダブルクリックします。
    Windows では「実行する」（Windowsバッチファイル）を実行します。曜日は自動的に判定されます。
  2. 処理の完了を待ちます。
    処理中に自動的にブラウザが開きますが、操作や終了の操作は行わないでください。ターミナル（黒い画面）もそのままお待ちください。
  3. 完了すると、当日作成されたファイルの一覧が画面に表示されます。
  4. 表示されたファイルを Google Drive へ格納します。
    手順は次の「Drive への格納」を参照してください。
注意

処理中に自動的に開くブラウザは、正常な動作です。クリックや終了の操作を行うと処理が中断します。月曜は時間を要しますので、画面を閉じずにお待ちください。

Drive への格納

作成したファイルは、以下の Google Drive フォルダへ格納します（ブックマークを推奨します）。

納品先 Drive フォルダを開く

Drive 内にはカテゴリごとのフォルダがあります。ファイル名に含まれるカテゴリと同じ名称のフォルダへ格納してください。

ファイル名に含まれる表記格納先フォルダファイル名の例

IN_DSIN（Drive 側の名称は「IN」）hrmos_IN_DS_item_list_….csv
CRSCRStalentio_CRS_item_list_….csv
CRGCRGhrmos_CRG_item_list_….csv
コンサルコンサルrikunabi_コンサル_item_list_….csv
補足

ファイルの保存場所は、「毎日の取得」フォルダ内の「output」です（HERP は「output」内の「herp」）。当日の日付が含まれるファイルが対象です。

実行した媒体のファイルをすべて格納すると、当日の作業は完了です。

4月次の集計作業（月1回）

月1回、障害者雇用の求人媒体5つからデータを取得し、納品用データを作成します。手順は3段階で、dodaチャレンジのみ手作業が含まれます。

全体の流れ

手順1：データ取得（自動）　→　手順2：dodaチャレンジの取得（手作業）　→　手順3：集計・納品

手順 1データを取得する

  1. 「①取得する.command」をダブルクリックします。
    Windows では「①取得する」（Windowsバッチファイル）。
  2. 処理の完了を待ちます（30分〜2時間程度）。
    自動的にブラウザが開きますが、操作や終了の操作は行わないでください。
  3. 「4媒体のデータ取得が終わりました」と表示されれば完了です。

手順 2dodaチャレンジを取得する（手作業）

dodaチャレンジは自動取得に対応していないため、ページの内容を手作業で取得します。

  1. Chrome で dodaチャレンジの求人検索結果ページを開きます。
    https://doda.jp/challenge/ から求人を検索します。
  2. 「もっと見る」ボタンを、表示されなくなるまで押します。
    すべての求人を1ページに表示させるための操作です。途中で中断すると取得件数が大きく減少しますので、最後まで押し切ってください。
  3. 求人一覧の上で右クリックし、「検証」を選択します。
    画面横に開発者ツールが表示されます。
  4. 求人一覧全体を囲む要素を選択し、右クリック → Copy → Copy outerHTML を選択します。
    開発者ツール上の各行にマウスを合わせると、ページ側の対応箇所がハイライトされます。求人一覧全体がハイライトされる要素を選択してください。
  5. 「dodaここに貼る.txt」を開き、既存の内容を削除してから貼り付け、保存します。
重要

「もっと見る」を最後まで押していない場合、一部の求人のみが取得され、件数が大きく減少します。取得件数の目安は1,800件前後です。著しく少ない場合は、押し残しの可能性をご確認ください。

補足：「もっと見る」の操作を自動化する場合（任意）

ボタンの押下回数が多い場合、ページを開いた状態で F12 を押して「Console」タブを開き、以下を貼り付けて Enter を押すと、最後まで自動的に展開されます。「完了」と表示されたら、上記の手順4へ進んでください。手作業による押下でも問題ありません。

(async () => {
  let clicks = 0, idle = 0;
  while (idle < 3) {
    const before = document.body.scrollHeight;
    window.scrollTo(0, document.body.scrollHeight);
    const btn = [...document.querySelectorAll('button, a, span, div')]
      .find(el => el.offsetParent !== null && el.textContent.trim() === 'もっと見る');
    if (btn) { btn.click(); clicks++; }
    await new Promise(r => setTimeout(r, 2000));
    if (document.body.scrollHeight === before && !btn) idle++; else idle = 0;
  }
  console.log(`完了: もっと見る ${clicks} 回クリック。全件展開済み`);
})();

手順 3集計して納品する

  1. 「②集計する.command」をダブルクリックします。
    数分で完了します。Windows では「②集計する」（Windowsバッチファイル）。
  2. 「7ファイルそろっています」と表示されれば完了です。
  3. 作成された「日付_集計」フォルダ（例：20260630_集計）を、フォルダごと Drive へアップロードします。
  4. 依頼元へ完了報告を行い、当月の作業は完了です。
    各媒体の件数サマリを添えると、確認が円滑になります。
「日付_集計」フォルダに含まれる7ファイル

atGP／LITALICO仕事ナビ／dodaチャレンジ／BABナビ／マイナビパートナーズ の各CSV（5件）、全媒体を統合した企業一覧（all_companies_deduped）、重複削除した企業の一覧（removed_duplicate_companies）。

注意

同一媒体の取得は1日1回までとしてください（取得先サイトへの負荷軽減のため）。

5トラブル対応

処理が停止した場合は、まず同じファイルをもう一度実行してください。多くの場合はこれで解消します。解消しない場合は、下表をご確認のうえ、お問い合わせください。実行画面のスクリーンショットを添えていただくと、対応が円滑になります。

状況対応
処理中に自動でブラウザが開く正常な動作です。操作せずにお待ちください。
処理がなかなか終わらない月曜（リクナビ・HERP）は1時間以上を要します。画面を閉じずにお待ちください。
ファイルの中身が空、または1行のみもう一度実行してください。解消しない場合はお問い合わせください。
「準備がまだのようです」と表示される先に「はじめにこれ」を実行してください（初期設定）。
（月次・手順2）「HTMLが貼られていないようです」手順2の貼り付けを行ったうえで、手順3を再実行してください。
（月次・手順3）「ファイルが7個ありません」画面の案内に従い、不足している媒体を手順1から再実行してください。
件数が前月から3割以上異なる媒体側の仕様変更の可能性があります。お問い合わせください。
（Windows）ダブルクリックで実行できない「初期設定」タブ内の「セキュリティの確認画面が表示され、実行できない場合」を参照してください。

6よくあるご質問

初期設定は毎回必要ですか。

いいえ。フォルダを受領した初回のみです。翌日以降・翌月以降は不要です。

土日に実行しても問題ありませんか。

問題ありません。土日は処理対象がない旨が表示されるのみで、処理は行われません。

実行中に他の作業をしても構いませんか。

差し支えありません。ただし、自動的に開いたブラウザは操作しないでください。なお、処理中はスリープを避けることを推奨します。

処理が途中で停止したようです。

同じファイルをもう一度実行してください。多くの場合はこれで解消します。解消しない場合は、実行画面のスクリーンショットを添えてお問い合わせください。

「プログラム本体」フォルダの中を確認しても構いませんか。

閲覧は差し支えありませんが、内部ファイルの編集・移動・削除は行わないでください。動作不良の原因となります。

ログイン情報（ID・パスワード）はどこにありますか。

「プログラム本体」内の credentials.yaml ／ config.yaml という設定ファイルで管理しています。これらは外部に共有されません。変更が必要な場合は担当者へご相談ください。
